# hyprland keybindings.

a cheat sheet for my keybinds.

## application launches

| keybind | action |
|---------|--------|
| alt + q | open terminal |
| alt + b | open librewolf browser |
| alt + e | open file manager |
| alt + space | open menu |

## window management

| keybind | action |
|---------|--------|
| alt + c | close window |
| alt + v | toggle floating window |
| alt + p | toggle pseudo tiling |
| alt + f | fullscreen window |

## system controls

| keybind | action |
|---------|--------|
| alt + shift + m | exit session |
| ctrl + alt + delete | open logout menu |
| ctrl + alt + shift + delete | reboot system |

## window & workspace navigation

| keybind | action |
|---------|--------|
| alt + tab | switch to next window |
| alt + shift + tab | switch to previous window |
| alt + left/right/up/down | focus window in direction |
| alt + shift + left/right/up/down | move window in direction |
| alt + 1–9 | switch to workspace 1–9 |
| alt + 0 | switch to workspace 10 |
| alt + shift + 1–9 | move window to workspace 1–9 |
| alt + shift + 0 | move window to workspace 10 |
| alt + s | toggle special workspace (scratchpad) |
| alt + shift + s | move window to scratchpad |
| alt + mouse wheel up/down | scroll through workspaces |

## mouse actions

| keybind | action |
|---------|--------|
| alt + mouse drag (left) | drag/move window |
| alt + mouse drag (right) | resize window |

## media & hardware keys

| keybind | action |
|---------|--------|
| volume up | increase volume by 4% |
| volume down | decrease volume by 4% |
| mute | toggle audio mute |
| mic mute | toggle microphone mute |
| brightness up | increase brightness by 10% |
| brightness down | decrease brightness by 10% |
| media next | skip to next track |
| media play/pause | play or pause media |
| media previous | skip to previous track |

## other

| keybind | action |
|---------|--------|
| super + s | take screenshot |
| super + l | lock screen |
